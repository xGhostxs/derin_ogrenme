| Parametre | Tanımlama / İçerik |
| :--- | :--- |
| **Seçilen Foundational Model** | **EVA-02-Base** (BAAI, 2023) — ViT-B/16 mimarisi (~86M parametre). ImageNet-22K üzerinde **Masked Image Modeling (MIM)** ile self-supervised ön eğitim, ardından EVA-CLIP modelinden **Knowledge Distillation** ile hibrit eğitilmiştir. |

## 2. FOUNDATIONAL MODEL DETAYLARI VE TEKNİK ALTYAPI

### 2.1. Mimari Özellikler (EVA-02)
* **Temel Yapı:** Vision Transformer (ViT-B/16), 86M Parametre, 12 Encoder Blok, SwiGLU aktivasyon fonksiyonları ve Sub-Layer Normalization (SubLN).
* **Ön Eğitim Stratejisi (Pre-training Paradigm):**
  1. **Aşama 1 (Self-Supervised MIM):** Görüntü yamalarının (patches) %16-20'si maskelenir. Model, maskelenmiş görsel sembolleri (visual tokens) kestirmeye çalışır.
  2. **Aşama 2 (Knowledge Distillation):** Mimarinin çıktıları, EVA-CLIP öğretmen modelinin ürettiği öznitelik dizilimlerini taklit edecek şekilde hizalanır.
* **Ön Eğitim Hata Fonksiyonu:**
  $$\mathcal{L}_{Toplam} = \mathcal{L}_{MIM} + \lambda \mathcal{L}_{KD}$$
  * $\mathcal{L}_{MIM}$: Maskelenmiş alanlar için *Cross-Entropy Loss*.
  * $\mathcal{L}_{KD}$: Öğretmen model ile öğrenci model arasındaki *Kullback-Leibler (KL) Divergence Loss*.

## 3. ADAPTASYON METOTLARI VE TEORİK FARK LİSTESİ

### 3.1. IA³ (Infused Adapter by Inhibiting and Amplifying Inner Activations)
* **Çalışma Prensibi:** Modelin orijinal ağırlık matrislerini ($W_0$) tamamen dondurur. Key ($K$), Value ($V$) ve Feed-Forward Network ($FFN$) aktivasyonlarını doğrudan çarpımsal öğrenilebilir vektörlerle ($l_k, l_v, l_ffn$) günceller.
* **Parametre Verimliliği:** Eğitilebilir parametre sayısı modelin genel büyüklüğünün yaklaşık **%0.01**'idir.

### 3.2. AdaLoRA (Adaptive Low-Rank Adaptation)
* **Çalışma Prensibi:** Klasik LoRA'daki sabit rank ($r$) yaklaşımı yerine, katmanların önem derecesine göre rank bütçesini dinamik olarak dağıtır. SVD (Singular Value Decomposition) esaslı budama (pruning) adımı kullanır:
  $$W = W_0 + P \cdot \Lambda \cdot Q$$
  Eğitim adımları ilerledikçe önemsiz parametreler sıfırlanır, kritik katmanlar daha yüksek rank ile eğitilir.

## 6. ÖRNEK ÇEKİRDEK KOD BLOĞU (JUPYTER IMPLEMENTATION)

```python
# ==============================================================================
# PROJE BAŞLATMA KODU (GÖREVLİ 1 & GÖREVLİ 2)
# ==============================================================================
import torch
import torch.nn as nn
import timm
from peft import IA3Config, AdaLoraConfig, get_peft_model, TaskType

# Hiperparametre Yapılandırması
NUM_CLASSES = 12
DEVICE = torch.device("cuda" if torch.cuda.is_available() else "cpu")

def build_pipeline(method="ia3"):
    # 1. Base Model Yükleme
    base_model = timm.create_model(
        "eva02_base_patch14_224.mim_in22k_ft_in1k", 
        pretrained=True, 
        num_classes=NUM_CLASSES
    )
    
    # 2. Adaptör Konfigürasyonu
    if method == "ia3":
        config = IA3Config(
            peft_type="IA3",
            target_modules=["attn.qkv", "mlp.fc1", "mlp.fc2"],
            feedforward_modules=["mlp.fc1", "mlp.fc2"],
            task_type=TaskType.FEATURE_EXTRACTION
        )
    elif method == "adalora":
        config = AdaLoraConfig(
            peft_type="ADALORA",
            target_r=8,
            init_r=12,
            target_modules=["attn.qkv", "proj"],
            task_type=TaskType.FEATURE_EXTRACTION
        )
    else:
        raise ValueError("Geçersiz metot seçimi!")
        
    model = get_peft_model(base_model, config)
    return model.to(DEVICE)

if __name__ == "__main__":
    ia3_test_model = build_pipeline(method="ia3")
    print("--- IA3 Model Yapısı Başarıyla Kuruldu ---")
    ia3_test_model.print_trainable_parameters()
```
